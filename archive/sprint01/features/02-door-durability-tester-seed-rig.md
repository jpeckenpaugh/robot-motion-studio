# Feature 02: Door Durability Tester Seed Rig

Capability: provide a new default seed rig — a non-humanoid, wall-mounted servo
arm (shoulder/pivot, elbow, wrist twist, and a gripper end-effector) intended
for repeatedly opening and closing a door over many cycles as a stress/
durability test. It ships with the arm's calibrated servos and angle limits, a
few named poses, and example motion sequences, and behaves exactly like
user-created data once present.
